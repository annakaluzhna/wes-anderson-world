# The Wes Anderson World

Інтерактивний вебпростір, присвячений фільмографії, візуальному стилю та палітрам режисера Веса Андерсона. Навчальний проєкт з дисципліни «Технології веб розробки та дизайну».

🔗 **Демо:** https://anderson-world.netlify.app/

### Можливості
* **Hero-секція з фоновим відео** та швидкими кнопками дій.
* **Адаптивна верстка:** мобільна, планшетна та десктопна версії з Pure CSS бургер-меню (без JavaScript).
* **Карусель кадрів:** знамениті стрічки з можливістю перегляду кольорових палітр.
* **Mood Quiz:** інтерактивний квіз для підбору фільму під настрій.
* **Персональний Watchlist:** збереження фільмів для подальшого перегляду.
* **Сторінки:** Головна, Фільмографія, Біографія, Mood Quiz, Watchlist, сторінка фільму.

### Технології
HTML5 · Tailwind CSS (CDN) · Pure CSS (Checkbox Hack для меню) · Google Fonts (Nunito, Pattaya)

### Запуск
Збірка не потрібна. Відкрийте `index.html` у браузері або запустіть через розширення Live Server у VS Code. Для завантаження Tailwind CSS та шрифтів потрібне підключення до інтернету.

### Публікація
Netlify → проєкт `anderson-world` → Deploys → завантаження папки проєкту.
